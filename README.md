# FIRMA · firmasvc.com

Web de FIRMA, Castro & Partners Legal Consulting: el home, la página de planes, el portal de clientes con CRM, firma electrónica y abonos, y los protocolos.

## Correr en tu compu

Requiere Node.js.

1. Instalá las dependencias: `npm install`
2. Copiá `.env.example` como `.env.local` y completá las variables.
3. Levantá la web: `npm run dev`

La configuración del portal, Supabase, Resend y dLocal Go está en [PORTAL.md](PORTAL.md).
